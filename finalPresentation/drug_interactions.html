The gap: The FDA collects 2M+ adverse event reports per year, but most are analyzed manually — there are no automated systems to detect novel drug-drug interaction signals at scale.
Our approach: Apply data mining to real FAERS reports to (A) discover which drug combinations are statistically dangerous, and (B) predict whether a new patient case will have a severe outcome.
What is FAERS?
FDA Adverse Event Reporting System — the world's largest pharmacovigilance database. Healthcare providers and consumers voluntarily report medication-related adverse events.

Each report contains: who the patient was, what drugs they took, what reactions they had, and whether the outcome was severe.
Real-world data. Real patients. Real interactions. The FDA has it — we mine it.

Each FAERS report is a basket: drugs + reactions as items. We mine statistical co-occurrences to find combinations where lift ≫ 1 — the drugs cause that reaction far more than chance.

Market Basket Model
Each report = 1 transaction. Items = drugs + reactions.
{METHOTREXATE, PREDNISONE, NAUSEA, FATIGUE}
We compare two item encodings:
  • Active substances (generic names) → consolidates brand-name redundancy
  • Brand names → more fragmented, lower quality rules
Winner: Active substances — same lift, less noise.
3 Key Metrics
MetricMeaning
SupportHow often does this combo appear? (≥0.25% of reports)
ConfidenceP(reaction | drug combo)
LiftHow much MORE likely than random? Lift=45 → 45× above chance
Lift is the key metric — it normalizes for reaction base rate.
Indication Bias Filter (Step 6A)
Raw rules include false positives like:
METHOTREXATE → RHEUMATOID ARTHRITIS
This is not an adverse effect — it's why the drug is prescribed.

The filter removes all rules where the consequent is a disease indication rather than an adverse reaction → from thousands of rules to 13 genuine DDI signals.

Why preserve NaN in age? Imputing globally before the train/test split would be data leakage — test set statistics would contaminate training. SimpleImputer is applied inside each model's sklearn Pipeline, fitted only on X_train.
✗ Leakage Detected & Removed

rxn_hospitalisation appeared as the #2 most important feature in early XGBoost (10.7% gain). On inspection: this MedDRA term directly encodes seriousnesshospitalization=1 — which IS part of our target variable.

Test: Removed it. AUC dropped 0.805 → 0.796. The drop confirmed the leakage was real.
12 death/hospitalization terms excluded from features.
AUC 0.796 is clean. AUC 0.805 (final) = Optuna tuning, not leakage.
Split strategy: 70% train / 10% val / 20% test (stratified). The val set is used only for threshold tuning — never for model selection. Final metrics reported on held-out test only.

TASK B: EVALUATION — CONFUSION MATRICES & PR CURVES

Normalized confusion matrices — all 5 models

Precision-Recall Curves — more informative than ROC for imbalanced classes

Why AUC-ROC, not accuracy?
A model that always predicts "not severe" gets 73.4% accuracy — better than any naive model. AUC-ROC measures ranking ability regardless of class imbalance.
Recall (severe) = 0.651 (Tuned Ensemble)
In clinical context, False Negatives (missed severe cases) are more dangerous than False Positives. Threshold ~0.54 optimizes F1-severe on val set.
Remaining challenge: Precision (severe) ~0.53. The model identifies most severe cases but with ~47% false positives. Acceptable for a screening tool; would need higher precision for clinical deployment.

FUTURE WORK & REFERENCES

Technical next steps:
  • Real-time FAERS API streaming — update rules as new quarterly reports arrive; detect emerging DDI signals before annual FDA reviews
  • GNN (Graph Neural Network) — model drug-reaction relationships as a knowledge graph; handle multi-hop interactions (drug A affects metabolism of drug B which then reacts with drug C)
  • Temporal trend analysis — track whether a DDI signal is increasing quarter-over-quarter (early warning system)
  • SHAP explanations — add patient-level explainability for clinical deployment ("this patient scored high because they are on LEUCOVORIN + FLUOROURACIL, which has lift=223 for GI toxicity")
Deployment vision: A pharmacist reviews a polypharmacy patient. The system flags drug combos that match Task A high-lift rules AND predicts severity probability. Not a replacement for clinical judgment — a second opinion at scale.
